## 🚀 Overview
Tech Grid is a high-octane, cyberpunk-inspired variant of the classic Criss-Cross (Tic-Tac-Toe) game. Engineered for hackathon environments, this project takes the traditional 3x3 board and expands it into a massive 9x9 matrix. 

To secure victory, players must claim an entire row, column, or diagonal—connecting 9 consecutive blocks from edge to edge.

## ✨ Features
- **Massive 9x9 Grid:** A highly expanded battlefield requiring deep strategy to lock out the opponent.
- **Edge-to-Edge Win Logic:** Custom algorithm requiring 9 unbroken marks to trigger a system win.
- **Cyberpunk UI:** Deep black `#050914` grid background with pulsing neon cyan `#00f3ff` accents and glowing victory states.
- **Client-Server Architecture:** Packaged with a lightweight Node.js/Express backend for instant deployment.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (CSS Grid), Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Typography:** Orbitron (Google Fonts)
